Raster vs vector: which to use for print

Raster is pixels. Vector is math. Using the wrong one is why a logo prints blurry, or why a file balloons to 400 MB. Here's the difference and exactly when to use each.

Raster: made of pixels

A raster image is a fixed grid of colored squares — pixels. Photos, scans, and anything from a camera are raster. Because the pixels are fixed, a raster image is resolution-dependent: enlarge it and the pixels spread out and get soft or blocky. Raster is perfect for photographs, where you need millions of subtly different colors — but it has to be captured at high enough resolution for the print size. (See 300 DPI.)

Raster file types: JPG, PNG, TIFF, PSD, GIF.

Vector: made of math

A vector file isn't pixels at all — it's a set of mathematical paths (points, lines, curves) and fills. Because it's math, it can be scaled to any size — business card or billboard — and stay razor sharp, with no resolution to worry about. Vector files are also tiny. This is why logos, type, icons, and line art should always be vector.

Vector file types: AI, EPS, SVG, and PDF (a PDF can carry vector art).

Which to use for what

  • Photographs → raster, at 300 DPI at final size.
  • Logos, type, icons, line art → vector, every time.
  • A design that mixes both (a flyer with a photo and a logo) → build it in a vector app (Illustrator/InDesign) and export a PDF, which keeps the logo and text vector and the photo raster.
The classic mistake: a logo handed over as a small PNG or JPG pulled from a website. Blown up on a banner, it falls apart. Always get the original vector logo (AI, EPS, SVG, or vector PDF) from the designer.

How to tell which you have

Zoom in, way in. If you start seeing little squares, it's raster. If the edges stay perfectly crisp no matter how far you zoom, it's vector. Or check the file type: JPG/PNG/TIFF are raster; AI/EPS/SVG are vector; PDF could be either.

FAQ

Can I convert a raster image to vector?
You can "trace" it (Illustrator's Image Trace, or auto-vectorizers), but it's a re-drawing, not a recovery — fine for simple logos, rough for photos or detailed art. Better to get the real vector original.
Why is my vector file huge?
Usually because it contains a big embedded raster image, or thousands of traced paths. A truly vector logo should be tiny.
Does vector have DPI?
No. DPI only applies to raster. Vector is resolution-independent — it's sharp at any size, which is exactly why logos and type belong in vector.
