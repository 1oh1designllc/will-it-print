Embedding fonts: why "it looks fine on my computer" breaks at the printer

A PDF can name a font without actually carrying it. When it reaches a press that doesn't have that exact font, the press substitutes another one — your text reflows, spacing breaks, or a whole different typeface prints. It's one of the most common silent rejections.

Why it happens

The font lives on your computer, not inside the file. So the PDF just says "set this in Brandon Grotesque" and trusts that whatever opens it has that font. Your machine does, so it looks perfect to you. The printer's RIP doesn't — so it swaps in something close, and your careful layout shifts. You never see it until the proof comes back.

Fix 1: embed all fonts (the normal choice)

Embedding packs the actual font data inside the PDF, so the press always has it. Keep your text editable and prints exactly as drawn.

  • Illustrator / InDesign: export with a PDF/X preset (PDF/X-1a or X-4) — it embeds fonts automatically. Or in the export dialog, make sure subsetting is set so all fonts embed.
  • Canva / Affinity: use "PDF for Print" — fonts embed by default.
  • Word / Publisher: File → Options → Save → Embed fonts in the file, then export as PDF.

Fix 2: outline the text (belt-and-suspenders)

Outlining converts your type to vector curves — there's no font left to go missing, so nothing can substitute. The trade-off: you can no longer edit the text, and very small type can lose a little crispness (no hinting). Use it when you can't embed, or when a font's license doesn't allow embedding.

  • Illustrator: select the type → Type → Create Outlines (Shift+Ctrl+O).
  • InDesign: Type → Create Outlines (do it on a copy — it's not reversible).
Tip: keep an editable master file, and only embed or outline on the exported copy you send to print — so you can still make changes later.

FAQ

How do I check if fonts are embedded?
In Acrobat: File → Properties → Fonts tab — embedded fonts say "(Embedded)" or "(Embedded Subset)". Or just run the PDF through Will It Print?, which flags any that aren't.
Do standard fonts like Arial need embedding?
Most presses have the standard fonts, so it usually works — but "usually" isn't "always." Embedding removes all doubt, so embed everything.
Does outlining reduce quality?
Not at normal sizes — outlines are vector and stay sharp. Very small text can look slightly less crisp because it loses font hinting, so for tiny type, prefer embedding.
